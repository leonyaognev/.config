### Описание
конфигурационные файлы моего райза для arch linux hyprland/bspwm

---

### использование

склонируйте репозиторий в домашний каталог и сделайте симлинки на каталоги .config/bin/ и .config/Images в свой домашний каталог

---

### установка:
```bash
git clone https://github.com/leonyaognev/.config.git ~/.config
ln -s ~/.config/bin ~/bin
ln -s ~/.config/Images ~/Images
exec fish
wallpaper
```
